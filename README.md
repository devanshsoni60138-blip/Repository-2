# Devansh's Stock Portfolio Tracker

A Python program that calculates the total value of a stock portfolio using sample prices stored in a dictionary.

## How to run
Make sure Python is installed, open a terminal in this folder, and run:
`python main.py`

## How to use
Enter a listed stock symbol and quantity. Type `DONE` when finished. Choose `yes` to save the result to `portfolio.txt`.

Note: The prices are sample values, not live market prices.
